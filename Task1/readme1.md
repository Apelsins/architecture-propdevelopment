## 1. Классификация данных
### 1.1 Публичные данные
Пример данных:
- Маркетинговые материалы
- Общедоступная информация на сайте

Оценка риска:
- утечка данных - незначительный
- потеря данных - незначительный
- искажение данных - значительный
- некачественные данные - незначительный
- обесценивание данных - незначительный

Для публичных данных только искажение является опасным. Например, что продаются квартиры со скидкой -45% процентов. Это явно ошибка.
### 1.2 Внутренние данные
Пример данных:
- Техническая документация
- Отчеты менеджеров

Оценка риска:
- утечка данных - значительный
- потеря данных - значительный
- искажение данных - значительный
- некачественные данные - значительный
- обесценивание данных - незначительный

Почти все риски имеют значительную опасность, кроме обесценивания. Если где-то будут старые данные, то несложно разобраться в ситуации и поправить это.
### 1.3 Конфиденциальные данные
Пример данных:
- ФИО
- Данные о просмотрах
- Данные о будущих скидках/подорожаниях

- утечка данных - критический
- потеря данных - критический
- искажение данных - критический
- некачественные данные - критический
- обесценивание данных - незначительный

Анологичная ситуация, как с внутренними данными, но +1 уровень. Тут недопустимы упущения.
### 1.4 Секретные данные
Пример данных:
- Планы развития компании
- Пароли, ключи шифрования

- утечка данных - критический
- потеря данных - критический
- искажение данных - критический
- некачественные данные - критический
- обесценивание данных - критический

Тут все строго, но могут послабления для некоторых данных.
Например, для планы развития компании должны быть всегда качественными, это критично. 
Но вот пароли могут быть некачественными и обесцененными, ничего страшного не случиться.
